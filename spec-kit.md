## GitHub Spec Kit Demo ##

### /speckit.constitution ##
The project will be built using React TypeScript frontend and Next.js as Backend
Keep APIs RESTFUL, stateless, and JSON-based.
The codebase should follows clean architecture with clear naming and separation 
of concerns so features remain easy to extend. 
The UI is responsive and built using Tailwind CSS with reusable components.

### /speckit.specify ###
Create a Quotes Management system.
The backend must support creating, reading, updating, and deleting quotes.

Each quote has an id, quote text, author, like count, and tags stored as a semicolon-separated string.
Likes are simple counters and must never go below zero.

Expose APIs to fetch all quotes, fetch a quote by id, fetch unique tags, and fetch unique authors.

Search Quotes feature with search by author and keywords, and preload available quotes.

The frontend must list all quotes, show quote details including author, tags, and like count, and support routing.
Implement loading states, error handling, and a responsive layout.

Seed Data: Seed random 20 quotes.
